### Project Description
[**Downer AI** is a deliberately useless chatbot designed to respond with calm, realistic pessimism instead of encouragement or toxic positivity.  
It features short demotivating replies, a mood tracker that only decreases, a daily dose of harsh reality, a “Vent to me” button for heavier responses, and multiple dark themes.  
The entire project exists purely for the absurdity of an AI that makes you feel slightly worse.]

### The Problem (that doesn't exist)
[People today suffer from too much hope, toxic positivity, and the dangerous belief that things might get better.
Downer AI exists to fix this crisis by gently crushing optimism, lowering mood on purpose, and reminding users that most things are temporary, disappointing, or pointless — so they can finally stop expecting improvement.]

### The Solution (that nobody asked for)
[We’re solving the serious crisis of “too much hope” with advanced emotional sabotage technology.

Every time you open Downer AI, it carefully detects any leftover positivity and replaces it with calm, realistic disappointment. The mood tracker slowly drains your spirit, the daily quote reminds you that most things don’t work out, and the red “Vent to me” button delivers an extra heavy reality check when needed.

By the end of the conversation, you’re safely free from dangerous optimism — mission accomplished.]

### Project Name
**Downer AI**

### Description
A deliberately useless chatbot that responds with calm, realistic pessimism instead of encouragement. It features short demotivating replies, a mood tracker that only decreases, a daily demotivating quote, Encouragement Mode, a “Vent to me” button, and multiple dark themes.

---

### Tech Stack

| Category       | Technology                  |
|----------------|-----------------------------|
| Frontend       | HTML, CSS, JavaScript       |
| Backend        | Python (simple server)      |
| AI Provider    | Groq API                    |
| Styling        | CSS Variables (for themes)  |
| Storage        | localStorage + .env         |
| Tools Used     | Google Antigravity          |

---

### Features
- Short, demotivating AI replies (max 1–2 sentences)
- Mood Tracker (only goes downward)
- Daily Dose of Reality
- Encouragement Mode (subtle disappointment)
- Red “Vent to me” button (heavier responses)
- 3 Themes: Default Dark, Deeper Black, Cold Blue
- Theme persistence using localStorage

### Setup & Run Commands

1. **Clone / Open the project folder**

2. **Create a `.env` file** in the root and add:
```env
GROQ_API_KEY=your_api_key_here
```

3. **Install dependencies** (if any):
```bash
pip install -r requirements.txt
```

4. **Run the app**:
```bash
python server.py
```

5. Open your browser and go to:
```
http://localhost:5000
```
(or whatever port the server shows)
